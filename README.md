# SQL Practice and Data Analysis

## Overview

This repository contains SQL exercises and mini-projects designed to develop my skills in relational database management, data retrieval, and data analysis.

## Projects

### 1. Student Enrollment and Academic Performance Analysis

* Designed relational tables for students, modules, and enrollments.
* Used JOINs to retrieve student enrollment and grade information.
* Applied aggregate functions and CASE statements to calculate average grade points by course.

### 2. E-Commerce Order Management and Customer Analytics

* Designed a relational database for customers, orders, products, and order items.
* Used JOINs to retrieve customer order histories and product details.
* Applied COUNT, SUM, and HAVING to analyse order volumes and customer spending.

### 3. Retail Sales Performance and Trend Analysis

* Analysed transaction revenue across geographical regions.
* Used date functions to investigate monthly sales activity and seasonal trends.
* Aggregated product quantities and revenue to investigate product demand.

## Skills Demonstrated

* SQL database creation and table relationships
* Primary and foreign keys
* SELECT, WHERE, ORDER BY, and GROUP BY
* INNER JOIN and LEFT JOIN
* Aggregate functions: COUNT, SUM, AVG, and MAX
* CASE statements and HAVING
* Date functions and business data analysis
